# 王国保卫战 6（Kingdom Rush Genesis）修改器

[English](README.md) · [下载 Windows 发行版](https://github.com/Hidessp/kingdom-rush-genesis-trainer/releases/latest)

支持随时切换**中文 / English** 界面，默认跟随 Windows 界面语言，也可使用发行包中的“启动中文版.cmd”或 `Start-English.cmd`。

适用于包含 `Kingdom Rush Genesis.exe` 和 `lua51.dll` 的 Windows LuaJIT/LÖVE 版本。已在作者本机游戏版本中验证；其他版本尚未验证，不适用于其他王国保卫战作品。

## 功能

- 金钱 +500、+100，直接编辑关卡金钱。
- 防御塔伤害倍率 +0.1，包含可追溯到防御塔的士兵、技能和投射物伤害。
- 防御塔技能冷却倍率 −0.1，最多 9 次，最低 0.1 倍。
- 前四项支持独立启用、关闭和自定义快捷键。
- 编辑解锁星星，历史下拉框按编辑顺序记录修改前的数量，可选择恢复。
- 编辑全局防御塔升级点数，独立的历史下拉框记录修改前的点数，可选择恢复。
- 编辑当前英雄、当前法术的升级点数，每个英雄、每个法术各自独立。
- 编辑兵营士兵数量（1～50），一键恢复每种兵营各自的原始数量。
- 显示当前数值、连接状态，支持窗口置顶。

## 安装与启动

1. 下载 `KR6Trainer-v1.0.0-Windows.zip`，解压到游戏目录，与 `Kingdom Rush Genesis.exe` 放在一起。保留 `src` 文件夹。
2. 关闭游戏。安装 **64 位 Python 3** 后双击 `Install.cmd`。Python 只用于安装或卸载；修改器运行依赖 Windows 自带的 .NET Framework 4.x。
3. 用原来的启动方式运行游戏，再打开 `KR6Trainer.exe` 或“启动中文版.cmd”。显示已连接后即可使用。
4. 窗口右上角可切换语言，选择会保存。

也可执行 `python install.py --game-dir "D:\游戏目录"`。

安装脚本修改你自己的游戏副本，原始 EXE 保存在 `.kr6-trainer-backup/Kingdom Rush Genesis.original.exe`，请保留。重复安装或更新会从该原始备份重新生成游戏程序。安装后需要重启游戏。安装脚本会核对原始归档条目的校验值和大小，兵营相关模块保持原样。

发行包和仓库只包含修改器及其源码，不含游戏本体、游戏素材、游戏 DLL、个人存档、账号凭据或玩家修改历史。

## 使用说明

在关卡内修改金钱；选中存档后修改星星，重新打开地图或解锁页面刷新。

编辑塔升级点数时，在游戏中打开全局“升级”页面。编辑英雄或法术点数时，先打开目标的升级树，确认修改器显示的名称再设置。每个对象独立保存，不改变等级、经验或已购买升级；正常升级仍会获得点数，购买升级仍会消耗点数。

星星和塔点数历史按存档区分，记录每次编辑前的数值，只记录顺序，不记录详细时间。恢复操作也会产生记录。恢复只恢复剩余数量，不撤销已购买升级或已领取奖励。历史与首次编辑前的存档快照保存在本地 `trainer-data/`。

伤害、冷却和兵营数量在当前游戏进程中有效，换关卡仍保留，重新启动游戏后恢复默认。星星、升级点数、历史和快捷键设置会保存。增加兵营人数后，游戏正常召唤流程会补齐；减少人数会移除多余士兵。一键重置恢复各兵营自己的原值，例如 1、2、3 或 8 名，而非统一数量。

快捷键默认关闭，仅在游戏窗口中生效。勾选启用，点击输入框并按下按键或 Ctrl / Alt / Shift 组合键，再点击“保存快捷键设置”。各功能不能使用相同组合。

## 卸载

关闭游戏，运行 `Uninstall.cmd`，或执行 `python install.py --uninstall --game-dir "D:\游戏目录"`。它会从备份恢复原始 EXE，保留存档和历史。卸载不会自动撤销已保存的星星或点数修改，需要时请先在修改器中恢复。

## 源码与验证

运行 `powershell -ExecutionPolicy Bypass -File .\build.ps1` 可编译修改器，需 .NET Framework 4.x，无 NuGet 依赖。`src/Trainer.cs` 为中英双语界面，`src/bridge.lua` 为运行时功能，`install.py` 为本地安装脚本。
