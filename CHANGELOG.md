# Changelog / 更新记录

## v1.0.0

- Initial public Windows release with English / 中文 UI and a saved language preference.
- Gold editing, tower damage and skill cooldown multipliers, configurable optional hotkeys.
- Unlock-star and global tower-point editing with ordered original-value history and restore.
- Independent upgrade point editing for the selected hero and spell.
- Barracks soldier count editing and per-type original-count reset.
- Local game-bridge installer, original-executable backup, update and uninstall support.

首次公开发行：中英双语界面、金钱与倍率修改、自定义快捷键、星星及防御塔点数历史恢复、英雄和法术独立点数、兵营数量及原值重置。安装脚本修改本地游戏并备份原始程序，支持重复安装和卸载恢复。
